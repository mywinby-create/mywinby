# 더하기 빼기 퀴즈 (초등학교 1학년)

초등학교 1학년 수준의 덧셈·뺄셈을 연습하는 웹 퀴즈앱입니다.
빌드 도구나 외부 라이브러리 없이 HTML·CSS·JavaScript만으로 동작합니다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 실행됩니다. 로컬 서버로 띄우려면:

```bash
npm start          # http://localhost:8000
```

## 화면

| 홈 | 문제 풀이 | 결과 |
| --- | --- | --- |
| 연산·난이도 선택, 최고 기록, QR 코드 | 큰 숫자 키패드, 진행 막대, 즉시 채점 | 별 점수, 틀린 문제 다시 보기 |

## 문제 구성

한 판은 10문제이고, 한 세트 안에서 같은 식은 겹치지 않습니다.

| 난이도 | 범위 | 예시 |
| --- | --- | --- |
| 1단계 · 한 자리 수 | 9까지의 덧셈과 뺄셈 | `3 + 4`, `8 − 5` |
| 2단계 · 십몇까지 | 10 모으기·가르기, 받아올림/받아내림 없는 계산 | `4 + 6`, `15 − 3` |
| 3단계 · 받아올림과 받아내림 | 18까지의 덧셈과 뺄셈 | `9 + 5`, `13 − 7` |

연산은 덧셈만, 뺄셈만, 섞어서 중에서 고를 수 있습니다.
난이도·연산별 최고 기록과 소리 설정은 브라우저(localStorage)에 저장됩니다.

## 홈 화면의 QR 코드

홈 화면 아래쪽에 현재 주소를 담은 QR 코드가 표시됩니다. 휴대폰 카메라로 비추면
같은 퀴즈를 열 수 있어, 교실이나 가정에서 화면을 보여 주며 공유하기 좋습니다.

- **주소 복사**: 현재 주소를 클립보드에 복사합니다.
- **주소 바꾸기**: QR 코드에 담을 주소를 직접 입력합니다. 예를 들어 이 앱을
  웹에 올린 뒤 그 주소를 넣어 두면, 파일을 직접 열어 볼 때(`file://`)에도
  공유용 주소가 담긴 QR 코드를 보여 줄 수 있습니다.

QR 코드는 `js/qrcode.js`에 직접 구현했습니다(바이트 모드, 버전 1~40, 오류정정
L/M/Q/H, 마스크 자동 선택). 외부 스크립트를 불러오지 않으므로 인터넷 연결이
없어도 QR 코드가 만들어집니다.

## 파일 구조

```
index.html        화면 구조 (홈 / 퀴즈 / 결과)
css/style.css     스타일
js/qrcode.js      QR 코드 생성기 (의존성 없음)
js/quiz.js        문제 생성과 채점 로직 (화면과 분리된 순수 로직)
js/app.js         화면 조작과 상태 관리
test/             node:test 기반 단위 테스트
```

## 테스트

```bash
npm test
```

- `test/quiz.test.js` — 난이도별 문제 범위(받아올림 유무 등), 중복 없는 출제,
  채점과 결과 요약을 검증합니다.
- `test/qrcode.test.js` — 규격 표와 같은 용량·버전 선택, 오류정정 코드워드,
  기능 패턴 배치, 매트릭스 회귀를 검증합니다. 기댓값은 실제 QR 디코더로
  읽히는지 확인한 결과를 기준으로 삼았습니다.

## 접근성

- 키보드로도 풀 수 있습니다(숫자 키 입력, `Backspace` 지우기, `Enter` 확인).
- 정답/오답 안내는 `aria-live`로 읽어 줍니다.
- 화면 확대 없이도 읽을 수 있는 큰 글씨와 큰 버튼을 사용했습니다.
- `prefers-reduced-motion` 설정을 존중합니다.
